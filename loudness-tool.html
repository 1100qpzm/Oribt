ORBIT 곡 업로드 · 음량 도구

곡 폴더를 점검해 library.json·업로드 스크립트를 만들어 줍니다. 음량은 새 곡과 음원이 바뀐 곡만 측정하고, 업로드도 바뀐 파일만 올립니다.

설정

작업

곡 폴더들이 바로 아래에 있는 폴더를 고르세요. 점검 → 음량 측정 → R2와 비교 → 곡 목록·난이도·음량·업로드 스크립트 생성.

목록·난이도·음량을 함께 편집하고 library.json 하나로 저장합니다.

R2 비교와 음량 측정은 공개 주소로 파일을 받아오므로, 브라우저가 CORS로 막으면 이 파일을 게임과 같은 주소에 올려서 열어 주세요. 현재 목록을 읽지 못하면 기존 정보를 보호하기 위해 작업을 중단합니다.

결과 파일

작업이 끝나면 여기에 결과 파일이 나옵니다.

    게임은 목표보다 큰 곡만 줄입니다(보정 0 dB 이하). 노란색은 목표보다 작아 원래 크기로 재생되는 곡입니다. 목표 음량만 바꿀 때는 다시 측정하지 않고 숫자만 바꿔 내려받으면 됩니다. R2에서 파일을 지우는 작업은 이 도구가 하지 않습니다.
